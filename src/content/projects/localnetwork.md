Local Network is a set of tools for nightlife. Each one stands on its own, and they share an Atmosphere account, a lexicon tree (`computer.localnetwork.*`), and file formats.

- [Local Network](https://localnetwork.computer), the website: promoters find local DJs, DJs keep a profile, and bookings run in member-only spaces.
- locallibrary, a command line tool and terminal player that keeps rekordbox USB drives in sync, backed up and edited.
- localtoolbox, a Chrome extension for digging on SoundCloud: track lists, download links, artists' socials, and a queue to batch them.

The website is SvelteKit, locallibrary is Rust, and the extension is Svelte on Manifest V3. All three live in one repo.
