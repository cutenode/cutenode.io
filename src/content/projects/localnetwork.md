Local Network is a set of tools for nightlife, for DJs and the promoters who book them. Each one stands on its own, and they share an Atmosphere account, a lexicon tree (`computer.localnetwork.*`), and file formats.

The website lives at [localnetwork.computer](https://localnetwork.computer). It's SvelteKit, locallibrary is Rust, and the extension is Svelte on Manifest V3, all in one repo.
