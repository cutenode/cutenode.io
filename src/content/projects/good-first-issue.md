A CLI that finds issues labeled "Good First Issue" to lower the barrier to contributing to open source. Run it bare for an interactive picker, or point it at one of the curated projects, any GitHub org or user, or a single repo.

```bash
npx good-first-issue node
```

Add `--open` to jump straight to the issue in your browser. If you want the same lookup inside your own code, use [libgfi](https://github.com/cutenode/libgfi).
