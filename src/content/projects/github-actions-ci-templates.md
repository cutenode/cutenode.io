Copy-paste workflow files for GitHub Actions. The JavaScript templates run your tests on Ubuntu, Windows, and macOS against every Node.js version the project currently supports, with variants for npm, Yarn, and pnpm.

Drop the YAML you want into `.github/workflows/` and name it whatever you like. PRs for new templates are welcome.
