The schemas for [upvote.at](https://upvote.at)'s public records and XRPC interface: `at.upvote.signal` for upvotes, `at.upvote.comment` for Markdown comments, and `at.upvote.settings` for each account's public settings. If you want to write upvotes from your own app, start here.
