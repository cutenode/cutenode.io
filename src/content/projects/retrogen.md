retrogen pulls GitHub activity for a user or organization and turns it into a Markdown retro. It's split into three packages: `@retrogen/core` gets the data, `@retrogen/templates` renders it, and `@retrogen/generate` puts the two together.

You'll need a GitHub personal access token. For a ready-made weekly setup, see [retro-weekly](https://github.com/cutenode/retro-weekly).
